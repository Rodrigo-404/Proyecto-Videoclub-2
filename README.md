# Proyecto Videoclub 2

---
## Ejecución del código
### 1. En el navegador
#### Url con path para probar el proyecto:
http://127.0.0.1:8080/videoclub2/main.php

> [!WARNING]
>Si se introduce la url sin el path `/videoclub2` el proyecto no funcionará.
>
>**Esto se hace con el objetivo de que se pueda mapear el apache de docker.**

Tras intentar configurar todo para evitar poner el path `/videoclub2`, he tenido 
que volver a aplicar esta configuración.

* **`XDebug` funciona perfectamente.**

### 2. En local
> [!NOTE]
> Funciona la ejecución de código mediante este IDE con y sin `XDebug`
